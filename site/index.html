两种形态，同一座馆

平时它缩成一条细长的观景窗，贴在屏幕底边。想玩的时候才铺开。位置不变，镜头的落点也不变。

点一下水面，鱼会自己来

挂件形态不打扰，所以整局的钱都是这么攒的。离线最多按 8 小时结算，打开的时候底部给一行提示。

  1. 01

    撒饵

    点水里任意一竖线，饵料先浮一下，再加速沉到终端速度，边沉边晃，落底停在沙上。

  2. 02

    抢食

    最近的鱼加速游过去吃掉。吃饱之后接下来两分钟产币翻倍。

  3. 03

    产币

    金币落到沙上，2.5 秒后自己进钱包。两种形态都一样，不点也会自己收。

  4. 04

    买鱼与扩建

    右侧商店买鱼、扩容量。买的鱼从水面扑通跳进来，落在看得见的那截水中间。

素材管线

像素是脚本画出来的

这个项目里没有一张手画的图。鱼、珊瑚、礁石、沙、远景、玻璃框，全是 tools/ 下的 Python 脚本跑出来的。

一条命令出图

python3 tools/make_art.py --preview
cd godot && godot --headless --import

出图到 godot/art/，验收图到 godot/shots/。色带暗部偏冷、亮部偏暖，光照是距离场从左上来，描边只描该描的那一圈。

全缸只有一套像素网格

整缸画在美术分辨率的 SubViewport 里再整数倍放大。Retina 下挂件形态 1 格 = 3 物理像素，展开形态 = 6。界面自己一套倍率，不跟缸走。

四个 shader

  • water 色带 + Bayer 抖动 + 斜光柱
  • caustics 两层扭曲网格取最小值
  • sway 按像素行整格平移
  • round 按 SDF 把整块缸裁成圆角

摇摆走 shader 是因为旋转会把像素拧斜，整格平移网格永远是正的。

看管线出的验收图

五种鱼，每种四帧摆尾自动生成。摆尾帧是脚本按轮廓和花纹推的，不是一张张画的。

存档就是一张 json

user://aquarium.json
  钱包 / 每区容量
  每条鱼：品种 / 展区 / 位置

改动时、每 15 秒、退出时各存一次。离线最多按 8 小时结算。数值只集中在 catalog.gd 一个文件里，调价只动它。

界面用的字也是像素

摸鱼水族馆 0123

缝合像素体 12px 简中，站上所有标题、标签、数字都是它，按 12 的整数倍放大。这一页的正文用系统无衬线，因为一整屏像素字读起来累。

四个里程碑

每个里程碑的验收都只靠 ./run.sh。所以画新素材单独占一个，不塞进玩法里程碑里。

  1. 完成

    三座馆

    缸切成三区 + 三种风格 + 镜头巡游。只用现有素材，零新美术。

  2. 完成

    钱

    存档、被动产币、买鱼、点水面投食、点金币收起来、扩建容量。

  3. 进行中

    素材

    淡水区、深海区真正的鱼种和布景。这一轮的验收命令和别的里程碑不一样。

  4. 待做

    生态

    配对下蛋孵化（基因混色 + 稀有突变）、离线结算框、图鉴、时间加速键、幼鱼成长。

跑起来只要一条命令

前提是本机装了 Godot 4.7。窗口会直接贴在桌面底边，右上角是钱包，左上角那个小挂耳点一下就展开。

启动 
./run.sh
重新出图 
python3 tools/make_art.py --preview
cd godot && godot --headless --import
自检截图 
godot --path . -- --shot=res://shots/out.png --wait=4
godot --path . -- --shot=res://shots/out.png --mode=expand --wait=5
godot --path . -- --shot=res://shots/out.png --zone=2 --wait=4
